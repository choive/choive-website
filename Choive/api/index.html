CHOIVE API

Run CHOIVE checks from your code

The CHOIVE API lets you start a check and read the score straight from your own app. You send a little bit of JSON, we send back a job, and you ask for the result when it is ready. That is the whole thing.
Want a key? Email hello@choive.com and tell us what you are building. We will send you an API key. Keep it secret — anyone with your key can use your daily checks.

1. Send your key with every request

Put your key in a header called X-API-Key. Every request needs it.

X-API-Key: your_key_here

If the key is missing you get 401. If it is wrong or turned off you get 403.

2. Start a check

POST /.netlify/functions/api-diagnostic

Send the same details a person would type on the website:

FieldNeeded?What it is
nameYesThe business name
websiteYesThe business website (for example taurbull.com)
categoryYesWhat kind of business it is
cityNoWhere the business is
descriptionNoA short line about the business
knownCompetitorsNoRivals you already know about

Example

curl -X POST https://choive.com/.netlify/functions/api-diagnostic \
  -H "X-API-Key: your_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Taurbull",
    "website": "taurbull.com",
    "category": "grass-fed beef delivery",
    "city": "Berlin"
  }'

You get back

{
  "jobId": "0f1c...-uuid",
  "status": "queued",
  "pollUrl": "/.netlify/functions/api-diagnostic?jobId=0f1c...-uuid",
  "usedToday": 1,
  "dailyLimit": 50
}

3. Get the result

GET /.netlify/functions/api-diagnostic?jobId=UUID

A check takes a couple of minutes. Ask for the result every 10–15 seconds until status is complete.

Example

curl "https://choive.com/.netlify/functions/api-diagnostic?jobId=0f1c...-uuid" \
  -H "X-API-Key: your_key_here"

While it is working

{ "jobId": "0f1c...", "status": "scoring", "stage": "scoring", "score": null, "result": null }

When it is done

{
  "jobId": "0f1c...",
  "status": "complete",
  "score": 63,
  "result": { "overallScore": 63, "inferredCategory": "...", "...": "full result object" }
}

How many checks can I run?

Each key has a daily limit (50 new checks a day to start). Reading results does not count. If you go over the limit you get 429 and can try again tomorrow. Need more? Just ask us.

Errors

CodeWhat it means
400Something in your JSON was missing or wrong
401You did not send a key
403Your key is wrong or switched off
404That jobId does not exist
429You hit your daily limit
500 / 502Something broke on our side — try again
